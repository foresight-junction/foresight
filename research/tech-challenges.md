## Details

### Best Use of Gemini API (Google DeepMind)
- **Ask:** open innovation challenge, no fixed problem. Build an agent, developer tool, creative app or anything else on the Gemini API.
- **Judged on:** a meaningful, innovative and technically impressive use of Gemini; show why Gemini matters to your solution.
- **Prizes:** 1st €4,000 + $1,000 Google Cloud credits per member; 2nd €2,000; 3rd €1,000.
- **Credits:** Gemini API credits, claim instructions "to be shared" (see challenges.md).

### Best Use of Gemma (Google DeepMind)
- **Ask:** most innovative and impactful use of Gemma open models.
- **Looking for:** creative applications, strong technical execution, open models solving real-world problems.
- **Prizes:** €1,000 per team for the top 3 teams, no ranking.

### Verda Compute Track (Verda)
- **Ask:** pick any Junction challenge and use Verda to build something you could not build on a laptop.
- **Their examples:** train locomotion/manipulation policies for Aalto's Unitree G1 in simulation; imitation-learning/VLA policies from Ignite x Intel robot-arm demos or Rokoko mocap; thousands of rollouts in your AfterQuery RL environment and fine-tune a smaller model; embed MariaDB's full Wikipedia dataset with batch jobs and serve RAG; run open-weight models in Europe for banking or recruitment tools. No crypto mining (ban).
- **Looking for:** an ambitious idea where compute makes it possible; the right Verda product and why; your path from idea to prototype; bonus for showing how it scales to real users.
- **Minimum requirements:** document your process; post a summary link in Verda's Discord channel.
- **Tech:** Inference API (open-weight models), GPU instances / Instant clusters (training, fine-tuning), CPU instances (agents), auto-scaling containers, batch jobs.
- **Prizes:** 1st $10,000 cloud credits + hoodies; 2nd and 3rd $2,500 credits. Credits: €200 per participant (challenges.md).

### Best Use of Codex (OpenAI)
- **Ask:** use Codex in your development process to build, iterate and ship an ambitious project. Open to any challenge.
- **Judged on:** demonstrating meaningful use of Codex in building the solution.
- **Prizes:** $10,000 / $5,000 / $2,500 API credits. Credits: $100 Codex credits per participant (challenges.md).

### Best use of Modal (Modal)
- **Ask:** use Modal to power the project you build for your main challenge: serve an open model on a GPU, run agent code in Sandboxes, fine-tune on your data, or fan out batch jobs, in plain Python.
- **Looking for:** the most ambitious working AI system on Modal, where Modal does the heavy lifting.
- **Mentors:** Modal engineers and DevRel (inference, agents, sandboxes, fine-tuning, RL, real-time audio/video); booth + Junction Discord. Contact: Filip Makraduli. Workshop Sat 13:30.
- **Prizes:** 1st $2,000 cash + $3,000 Modal credits. Credits: $100 per participant (challenges.md).

### Best Use of Aiven (Aiven)
- **Ask:** use at least one Aiven service as a meaningful part of your project and show what it enables. Enter alongside your main challenge.
- **Services:** Aiven Runtime (host app/agent), PostgreSQL, Valkey (cache), Kafka (events), ClickHouse (agent observability), OpenSearch (search). One service done well counts as much as several.
- **Prizes:** €1,000 / €750 / €500. Credits: $50 on signup.

### Best agentic usecase of Oxylabs Web API (Oxylabs)
- **Ask:** make your main-challenge agent act on what is true on the web right now: search to find, scrape to read, with cited sources.
- **Ideas:** cross-country price comparison; fact-checker that reads full sources; "what does AI say about you" vs the web; watchers for regulations, tenders, grants or competitors.
- **Minimum requirements:** at least one live /search or /scrape call at runtime (pre-downloaded data does not count); show the source URLs behind what it states.
- **Submit:** same repo and demo as main challenge, plus a note on which endpoints and why.
- **Prizes:** €1,000 Apple voucher + $500 Oxylabs credits per member.

### Best Use of Context.dev: Fully Structured Web (Context.dev)
- **Ask:** use the Context.dev API to pull live web data (pages, brands, companies, people, news) as structured data.
- **Minimum requirements:** at least one endpoint in the core flow, not a side feature; the data must visibly drive something in the demo.
- **Submit:** GitHub repo + demo + note on which endpoints and why.
- **Prizes:** €750 + swag / €250 + swag / swag. Credits: 50,000 per team (code in challenges.md).

### Best Use of Cloudinary (Cloudinary)
- **Ask:** solve a real problem through images/video using one of the four tools on cld.media/hackathons.
- **Submit:** must fill https://cld.media/hackathon-survey.
- **Mentors:** Jen Looper, Balazs Kemenesi.
- **Prizes:** $500 Amazon gift card per member (1st).

### Best Use of Nemotron (NVIDIA)
- **Ask:** a project where NVIDIA Nemotron does real work (reasoning, tool use, workflows) for a clear audience. Any track.
- **Minimum requirements:** use Nemotron 3.5 Super VL in the working solution; make its contribution visible; submit a text explanation (model, what it does, why it matters, how you improved outputs) in the submission form.
- **Access:** NVIDIA Build free API (OpenAI-compatible, base URL https://integrate.api.nvidia.com/v1, ~40 req/min per key, use one key per teammate + backoff); OpenRouter (:free variants 20 req/min, 50/day); Hugging Face weights.
- **Judged on:** meaningful Nemotron usage; technical execution; quality of AI output (prompting, evals, feedback loops); creativity.
- **Contacts:** Elliot Winch (ewinch@nvidia.com); mentors Maxime Pariente, Ryan Reese.
- **Prizes:** RTX 5080 for each of the 2 best teams.

### Best use of Arduino Uno Q (Arduino)
- **Ask:** use the UNO Q and Modulino sensors in any project; run AI on the device, sense the world, make things move or react.
- **Looking for:** a working physical prototype with smart on-device AI.
- **Prizes:** UNO Q + Plug and Make kit per member of the winning team. Kits from the Hardware Lab, 5th floor.

### Atech Real World Challenge (Atech)
- **Ask:** a physical device that solves a real problem for a real person, Atech modules as body and AI as brain. Atech hardware required.
- **Minimum requirements:** Atech modules used in the demo; post a summary in their Discord.
- **Submit:** live demo on hardware; public GitHub repo or exported Atech project; ~2-minute video or live demo.
- **Tech:** snap-together ESP32 modules (distance, IMU, temp/humidity, air quality, mic, speakers, motors); firmware generated from plain language at atech.dev, flashed from Chrome/Edge; `pip install atech`; emulator. 2-4 kits per team, limited.
- **Prizes:** Pro Atech kit; runners-up kits + swag + invite to Copenhagen.

### Best use of CRACI (CRACI)
- **Ask:** any project whose CI/CD runs on CRACI (`runs-on: craci`); use its build data and AI vulnerability fixing in creative ways.
- **Mentors:** Juho Niemi, Dennis Marttinen, Petteri Pulkkinen, Veeti Poutsalo, Roope Ripatti (booth).
- **Prizes:** LEGO set per member / 24-pack Red Bull per member / CRACI x OpenAI lunch at Slush.
